# ELIZA Simulator

A simple web-based ELIZA chatbot simulator built using **HTML, CSS, and JavaScript**.  
This project recreates the basic behavior of the classic ELIZA chatbot with a professional **1990s-style program interface**.

## Live Demo

Access the deployed project here:

[https://manuka-rashen.github.io/eliza-simulator/](https://manuka-rashen.github.io/eliza-simulator/)

## Project Overview

ELIZA is one of the earliest and most influential chatbot programs in the history of Artificial Intelligence. It was developed in the 1960s by **Joseph Weizenbaum** at the Massachusetts Institute of Technology.

The original ELIZA program was designed to simulate a conversation between a human user and a computer. The most famous version of ELIZA was called **DOCTOR**, which imitated a Rogerian psychotherapist by asking reflective questions.

This project is a browser-based ELIZA simulator that demonstrates how early chatbots used simple rule-based techniques to create the illusion of intelligent conversation.

## Purpose of the Project

The purpose of this project is to demonstrate the concept of a **rule-based AI chatbot** using simple web technologies.

This simulator helps users understand:

- How early AI chatbots worked
- How pattern matching is used in conversation systems
- How predefined responses can simulate human-like interaction
- The historical importance of ELIZA in Artificial Intelligence
- The difference between early rule-based AI and modern AI systems

## Features

- ELIZA-style chatbot conversation
- 1990s Windows-style user interface
- Single-page web application
- Letter-by-letter typing animation for bot replies
- Message sending using the **Enter** key
- Message sending using the **Send** button
- Input field disabling while the bot is typing
- Scrollable chat window
- Historical note section about ELIZA
- Responsive layout for different screen sizes
- Built using only HTML, CSS, and JavaScript
- No external libraries or frameworks required
